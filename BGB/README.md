# Biogeographic inputs, fits and complete node probabilities

The root directory contains the frozen 417-species tree and geographic matrix, the 11-area dictionary, the five-epoch time grid, the M1 and M2 dispersal multipliers, and the three-model comparison. The M0, M1 and M2 directories contain the fitted model objects, parameter tables and ancestral probability matrices. M1 is the specified primary model; M0 and M2 provide the stated model comparisons. `M1/postfit_recalculated_ancestral_states.rds` is the exact postfit object used by the conditional stochastic-history analysis.

`Results/M0_node_posteriors.tsv`, `M1_node_posteriors.tsv` and `M2_node_posteriors.tsv` provide complete node-state probabilities, retaining all 562 states for every tree node. `model_sensitivity_internal_nodes.tsv`, `root_three_model_summary.tsv`, `node_summaries.tsv` and the area-inclusion tables document the model comparisons and all 416 internal nodes. `Inputs` supplies connectivity grades, matrix rationales and related source tables. State labels and node identifiers join to `state_dictionary.tsv` and `nodes.tsv` at this directory's root.

`Computation/03_scripts` contains the original input checking, DEC fitting, postfit reconstruction and probability-export calculations. These scripts expect the original project-relative `01_inputs/frozen`, `02_config`, `04_runs` and `07_tables` layout. Use `file_locations.tsv` to restore those paths in a separate working copy; existing scientific inputs and fits are intentionally stored once in this repository. The calculation scripts retain original checks and recorded execution context. The tables and model objects can be inspected directly without rerunning the calculations. The stochastic-history inputs, outputs and methods are documented in `../BSM`.
