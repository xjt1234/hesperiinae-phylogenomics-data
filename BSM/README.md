# Conditional stochastic histories and complete event summaries

`BSM_tables.zip` contains the 300 retained histories, `map_0001.rds` through `map_0300.rds`. Each member is byte-identical to the current M1 history used for the reported summaries. The histories are conditional on the fixed tree, geographic data and fitted parameters. `bsm_run_manifest.json` records the sampling configuration.

The root event tables provide complete anagenetic and cladogenetic events, total event counts, all routes and epochs, local contractions by area, time-bin rates and convergence checkpoints. `Results` adds per-history route shares, macro-route/epoch counts, temporal rates and top-route contributions. The maps, source-area imputation and lineage-time normalization are implemented in the archived R and Python code under `Computation/03_scripts`. The endpoint-conditioned uniformization bridge is in `09_bsm_vendor_20260914/74_ctmc_uniformization_bridge_20260908.R`; `10_run_R4_bridge_bsm_20260914.R` uses this helper and the recorded fixed contract. The 30/31 scripts audit and aggregate the resulting maps. See the manuscript and supplementary methods for the biological interpretation of these conditional outputs.

The source code preserves its original checksum pins and project-relative input/fit paths. `Computation` includes the small configuration and numerical-check dependencies read by that runner; `file_locations.tsv` maps already deposited inputs and duplicate files to their original locations. Restore the original layout in a separate working copy rather than editing the repository's only copy of a result. The M1 fit and exact postfit object are under `../BGB/M1`; the existing geographic inputs are under `../BGB`. The supplied histories and tables can be analysed directly. No sampling or model fitting was rerun for this deposit.
