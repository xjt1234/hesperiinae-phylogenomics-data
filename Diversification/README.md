# Diversification data and computation

The files at this directory's root contain the 417-tip chronogram, the environmental series, ten-model fit objects and full-precision comparison, and the boundary-model diagnosis. `Results` adds optimization runs, rate-curve tables, numerical sensitivity and boundary-profile results. The ten candidates include one boundary case; its state and eligibility are retained in the data rather than inferred from a missing rate curve.

Original scripts are under `Computation`. `02_environment/rebuild_temperature.R` reconstructs the temperature series from CENOGRID and the supplied historical surface-temperature input. `code/03_fit_models_v2_fixed.R` performs the ten-model fitting. The 03b/03c/03d scripts retain the rescue, boundary-profile and integration-step diagnostics used in the final analysis; `03e_finalize_boundary_aware_v5_complete.R` assembles the final comparison. Its checksum-pinned v4 scripts are required dependencies of that finalizer, not alternative reported model results. The source functions under `code/vendor/Toussaint2025_diagnostics` are the original likelihood/helper implementations attributed to Toussaint et al. (2025) in the manuscript; preserve that attribution when using them.

Original scripts preserve their run-relative paths and checksum checks. Stage a separate run directory and place the existing root chronogram under `01_tree`, the existing processed temperature table under `02_environment`, and CENOGRID under `02_environment/input`. The extra historical surface input and original temperature-conversion script are already under that hierarchy in `Computation`. Install the packages listed in the original software/session records. A full model refit is computational work and was not performed when these files were prepared. `file_locations.tsv` maps source archive members to their repository locations; no manuscript-writing or figure-rendering scripts are needed to inspect these results.
