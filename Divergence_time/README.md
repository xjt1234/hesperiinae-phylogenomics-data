# Divergence dating data and computation

The two dated trees at this directory's root are the primary Scenario A and three-calibration Scenario B chronograms. `Inputs/CALIBRATION_DEFINITIONS.tsv` gives the calibration bounds; `Results` contains node ages, the full-precision focal-node comparison and calibration/leave-one-out summaries. The A/B subdirectories retain separate results and configurations.

`Computation/A_primary` and `Computation/B_sensitivity` contain the original treePL configurations and analysis scripts. The configurations record smoothing grids, random seeds, bounds and final optimization settings. `Computation/common` contains cross-scenario calculations, the randomCV parent-index patch, its software license and version record. Build treePL separately; executable binaries are not distributed here. To rerun, use a separate working directory, preserve the numerical settings and change the original server input/output paths to local paths. Run prime and each scenario's complete randomCV grid before its final configurations; the corresponding R scripts summarize grid scores and node ages. These are archived scientific scripts, not a one-command portable workflow.

The AHE nucleotide alignment is already in `../Sequence/AHE/Hesperiinae_NT_supermatrix.fasta`. `Inputs/alignment_label_crosswalk.tsv` maps all 495 dating labels to repository records with identical complete aligned sequences. This avoids a second 91 MB copy whose differences are tip labels and formatting. Identical-sequence records are listed together where relevant. The input tree retains the exact dating labels. Source locations and duplicate-file mappings are recorded in `file_locations.tsv`.
