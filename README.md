# hesperiinae-phylogenomics-data
Trees, matrices, partition files, and derived results for the Hesperiinae phylogenomics study

## Data organization

| Directory | Contents |
| --- | --- |
| `Sequence` | AHE, USCO and UCE alignments |
| `Partition` | Partition and constraint files |
| `Tree_file` | Phylogenetic trees; genus-level source tables and calculations in `Generic_summary` |
| `Backbone_pick` | Backbone-selection results |
| `Uce_probe` | Hesperiinae-v1 bait set and probe information |
| `Divergence_time` | Dated trees, calibration and cross-validation inputs, full-precision ages and calculation sources |
| `Diversification` | Temperature and tree inputs, fitted models, full-precision model comparisons and calculation sources |
| `Wolbachia` | WolDB, recovered sequences, trees, host-association and reconciliation data, results and calculation sources |
| `BGB` | Biogeographic inputs, fitted objects, complete node probabilities and scenario comparisons |
| `BSM` | 300 stochastic histories, complete event-summary tables and conditional stochastic-mapping calculations |

## Analysis documentation

The module README files describe the calculations and locate their inputs and results.
The original calculation sources retain their execution paths and scientific checks;
the accompanying file-location tables map archived project paths to this repository.
Genus-level tables and their supporting calculations are in
[`Tree_file/Generic_summary`](Tree_file/Generic_summary).

Supplementary Tables S1–S10, supplementary methods and Figs S1–S9 accompany the article.
